# Certification Options

Certifications are **optional**, not conditions for completing the programme. Choose exams based on relevance, readiness, availability and cost.

| Area | Possible credentials |
| --- | --- |
| Observability | Datadog Fundamentals and relevant specialist credentials |
| AWS | Cloud Practitioner; Solutions Architect – Associate |
| Terraform | Terraform Associate |
| Kubernetes | KCNA; Certified Kubernetes Administrator (CKA) |
| Platform Engineering | Relevant CNCF / Linux Foundation credentials |
| Developer portals | Backstage credentials, if offered |

Datadog is part of **Weeks 14–15 (D06)** whether or not an exam is taken. Exam preparation may run alongside the technical curriculum.

Verify exam names, versions, prerequisites and prices directly with the provider.
