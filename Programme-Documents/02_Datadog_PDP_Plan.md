# What counts as evidence

Prioritise the official Datadog Fundamentals exam credential and submission to DVT. A learning-path completion badge alone should not be assumed to satisfy the certification KPI. Verify internal submission method and manager acceptance.

# Six-step exam preparation plan

## 1. Confirm KPI

Request weighting, reimbursement policy and evidence-submission instructions.

## 2. Read guide

Open current Datadog Fundamentals official exam guide and map every objective.

## 3. Train

Complete Datadog learning path and Agent/configuration labs.

## 4. Practise

Set up host monitoring, dashboards, monitors and common Agent troubleshooting.

## 5. Assess

Take official practice assessment; revise weak objectives before booking.

## 6. Certify and file

Sit exam; retain credential, proof of passing, submission record and manager acknowledgment.
