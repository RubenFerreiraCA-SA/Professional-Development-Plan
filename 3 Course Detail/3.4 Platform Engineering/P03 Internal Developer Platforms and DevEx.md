**Purpose:** Treat Harbour as a **product for developers** — golden paths, self-service, cognitive load and independent usability evidence.

## Module overview

A developer who finishes DevOps, Cloud and optional AI may still not know how to design a platform others want to use. P03 is the programme’s product-thinking core: users, jobs-to-be-done, paved roads, ownership, onboarding, discoverability, safe self-service and adoption.

**Installing a developer portal is not sufficient.** A catalogue without a working golden path fails this module.

## Learning outcomes

1. Write a short platform product brief: users, JTBD, first golden path, success metrics.  
2. Reduce cognitive load: one recommended path for create → build → deploy → observe.  
3. Provide stranger-usable docs and an approved interface (CLI, template, portal — tool choice is flexible).  
4. Run an **independent** trial: a developer who did not build Harbour completes create, deliver, status and failure investigation with no undocumented author help.  
5. Record stuck points, intervention grades, independent completion time and product changes made from feedback.

## Practical labs and deliverables

- Product brief + golden-path diagram.  
- Template/scaffold and written developer instructions.  
- Trial protocol, consent and measurement sheet (stuck points, I0–I3 interventions, timings).  
- Feedback → backlog of platform fixes (at least one change shipped or honestly deferred with reason).

## Assessment and completion criteria

**Pass standard (audit):** Give a developer who has **not** built Harbour the project documentation and approved interface. They must create a new service, follow its delivery path, understand operational status and find information to investigate a failure — with **no undocumented help** from the platform author. Measure where they got stuck, which decisions needed platform-team intervention, which tasks completed independently and how long the experience took.

**Acceptance (Competent):** Trial user stands up a service from the golden path without 1:1 help beyond written docs; feedback captured; undocumented intervention fails the trial (re-run with a new participant after fixes).

**Evidence:** Template/portal, stranger-usable docs, trial feedback — Checklist P03. A portal screenshot alone does **not** pass.

## Certifications (optional)

No single industry cert covers IDP product work; prefer trial evidence over badges.
