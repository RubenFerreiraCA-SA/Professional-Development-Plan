# DevOps Engineering — Textbook

*A progressive guide to building, securing and operating the foundations of an Internal Developer Platform.*

This is **one textbook with eight chapters**. Every `DXX` file is a chapter; the numbered sections within it use the chapter number: **Section 1.1, 1.2 …** for Chapter 1, **Section 2.1, 2.2 …** for Chapter 2, and so on. Smaller topics are numbered **1.1.1**, **1.1.2**, etc.

The existing [D00 DevOps Syllabus](../../3%20Course%20Detail/3.1%20DevOps/D00%20DevOps%20Syllabus.md) and [D01–D08 course-detail documents](../../3%20Course%20Detail/3.1%20DevOps/) remain separate curriculum specifications; this book is the teaching material.

## How to study

Start with Chapter 1 and continue in order. Chapters introduce a subject from its own fundamentals and build towards challenging engineering decisions, progressively harder exercises and a **Practical Assessment**. Work on the same Final Project wherever practical; use disposable repositories for destructive experiments.

Chapters 3–8 will be added as their textbook material is developed. The chapter numbers are fixed even when a file has not yet been written. Study-hour estimates belong to the course detail and should not dictate the depth of the teaching.
