# Study Materials

This folder contains the **textbook-style learning material** for the professional development pathway. It complements, rather than replaces, [Course Detail](../3%20Course%20Detail/), which defines module outcomes, topic coverage and Practical Assessments.

Each textbook starts with the foundations of its subject, then layers explanations, worked examples, exercises, verification and increasingly demanding engineering challenges. The existing course-detail documents remain the curriculum reference.
