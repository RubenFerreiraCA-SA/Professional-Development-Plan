# T-DEV-04 — Infrastructure as Code and Terraform

*Part 1 — DevOps Engineering*

Infrastructure as code (IaC) describes infrastructure in versioned text that is reviewed, tested and applied by tools. Terraform is the most widely used declarative tool; the lessons — state, plans, modules, drift, least-privilege automation — apply to every IaC tool. This chapter takes you from a first disposable configuration to the design of safe, large-scale infrastructure change.

Read **Beginner** if you have never used Terraform: declarative versus imperative, providers, resources, state, the plan/apply workflow and a first disposable example with cost safeguards. Read **Intermediate** when you can apply a configuration but need variables, modules, the dependency graph, remote state, import and move operations, environment layouts and a method for plan and apply failures. Read **Professional** to design trustworthy delivery: state security, review workflows, policy checks, module contracts, secrets, safe migrations, testing, rollback limits and ownership. Read **Expert** for large estates: cross-account design, state partitioning, large migrations, policy and drift at scale, module ecosystems and complex recovery. Higher levels include short pointers back to earlier ones; they do not depend on the course or any project repository.
