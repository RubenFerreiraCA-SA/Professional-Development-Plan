# T-DEV-01 — Repository Management and Git

*Part 1 — DevOps Engineering*

A repository is more than file storage. It is the interface through which an engineering organisation decides who may change what, what must be reviewed, and how a deployed artifact can be traced back to a reviewed change. This chapter joins repository architecture and governance with the Git mental model needed to work, collaborate and recover safely.

Read **Beginner** if Git is new. Read **Intermediate** when you can commit and push but need a reliable mental model for merges, conflicts and recovery. Read **Professional** to design enforceable team repository practice. Read **Expert** for organisation-scale governance, advanced history operations and adversarial failure modes. Higher levels include short pointers back to earlier ones; they do not depend on the course or any project repository.
