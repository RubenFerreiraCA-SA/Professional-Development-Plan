# 1.3 How To Use The PDP

## The learning loop

1. **Assess** every topic in [2.2 Topic Self Assessment](../2%20PDP%20Development/2.2%20Topic%20Self%20Assessment.md).
2. **Build** your [2.3 Personal Learning Pathway](../2%20PDP%20Development/2.3%20Personal%20Learning%20Pathway.md).
3. **Schedule** work in [2.4 Capacity And Study Schedule](../2%20PDP%20Development/2.4%20Capacity%20And%20Study%20Schedule.md).
4. Open the **first assigned course module**.
5. Read the **first heading** — the Project Prerequisites gate — and stop if required project steps are incomplete.
6. Complete missing steps in the [Project Document](../4%20Project%20Document/Project.md).
7. Study the linked sections in the [Master Textbook](../5%20Textbook/Master%20Textbook.md).
8. Pass the module knowledge assessment; complete the assigned project step; record progress.
9. Move to the next assigned module.

## Where to start today

1. Read [1.1 Programme Vision](1.1%20Programme%20Vision.md) and [1.2 Programme Structure](1.2%20Programme%20Structure.md).
2. Complete [2.1 Personal Profile](../2%20PDP%20Development/2.1%20Personal%20Profile.md).
3. Complete the full 24-topic self-assessment.
4. Open your first module — the gate will tell you whether project catch-up is required.

## Important rules

- Self-rating chooses **theory entry level**. It does **not** skip earlier project steps.
- Lower theory modules you skip are **Not assigned — prior knowledge**, not Completed.
- Keep three progress states separate: topic assessment, course modules, project steps.
- Implement practical work in **your own repository**, not inside this PDP repo.
