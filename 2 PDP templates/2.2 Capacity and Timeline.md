# Capacity and Timeline

**Goal:** given how many hours you can study each week, estimate **how long the programme will take** and produce milestone dates you can live with.

This planner answers **when** — not whether the platform passed acceptance (see [Final Project Checklist](../1%20Foundational%20Documents/1.5%20Final%20Project%20Checklist.md)) and not the session-by-session learning record (see [Progress Log](2.4%20Progress%20and%20Evidence%20Log.md)). Relationships are spelled out in the [How To Guide](../1%20Foundational%20Documents/1.3%20How%20To%20Guide.md).

The working calculator is [`PDP Capacity Planner.xlsx`](PDP%20Capacity%20Planner.xlsx). This page explains the method and gives a quick lookup if you only need a rough answer.

## What you enter

| Input | Guidance |
| --- | --- |
| **Hours per week** | Sustainable average, not a heroic sprint. Only count time you can keep most weeks. |
| **Start date** | First week you will study. |
| **Estimate band** | **Low** / **Mid** / **High** from the [Course Outline](../1%20Foundational%20Documents/1.2%20Course%20Outline.md) ranges. Use Low if you already hold many skills; High if most topics are new. |
| **Experience adjustment (%)** | Extra fine-tuning after the band (e.g. `-20` if you will move faster than Mid; `+15` if labs usually overrun for you). |
| **Buffer weeks** | Holidays, illness, heavy work periods. Added **after** study weeks. |
| **Include Yes/No** | Per module on the *Module Plan* sheet — this is how you plan a shorter pathway. |

## How duration is calculated

```text
planned hours (module) = catalogue hours for your band × (1 + adjustment/100)
total planned hours    = sum of planned hours for modules with Include = Yes
study weeks            = total planned hours ÷ hours per week
calendar weeks         = study weeks + buffer weeks
end date               ≈ start date + calendar weeks
```

Discipline milestones use the same weekly rate and the cumulative hours through the last included module of that discipline.

Completion is still judged by **demonstrated outcomes**, not by hitting the end date.

### Example

> “I can do **10 hours/week**, start **17 Nov 2026**, Mid estimates, 4 buffer weeks, full pathway.”

- Study weeks ≈ 662 ÷ 10 = **66.2**
- Calendar weeks ≈ 66.2 + 4 = **70.2**
- End ≈ **mid‑March 2028**
- DevOps alone ≈ 221 Mid hours ≈ **22 weeks** of study before Cloud

Change hours/week or drop modules in the spreadsheet to see the plan move.

## Building the detailed plan

1. Open **`PDP Capacity Planner.xlsx`** → sheet **1. Inputs** and set capacity.
2. On **2. Module Plan**, leave **Include = Yes** for your pathway (or set **No** to skip/defer).
3. Optionally override **Planned hours** for a module when you have a better personal estimate (replacing the cell formula).
4. Read **target start/end** per module and discipline milestones on **1. Inputs**.
5. Optionally fill **3. Weekly Rhythm** so the weekly hour number maps to real calendar slots.
6. Copy the summary figures into [Personal Profile](2.1%20Personal%20Profile.md).
7. Track execution in [Progress and Evidence Log](2.4%20Progress%20and%20Evidence%20Log.md) (or sheet **4. Progress Log**).

If you cannot use a spreadsheet, copy [Module Schedule](2.3%20Module%20Schedule.md) and compute `weeks = planned hours ÷ weekly hours` by hand.

## Re-plan when reality changes

Update the planner when weekly capacity changes, a module takes longer, or you cut/add scope. Keep a short note in your profile of what changed and why.
