# PDP Templates

Use these templates to turn the programme into **your** plan: set weekly capacity, see how long the pathway will take, then schedule modules and track evidence.

Keep three progress views distinct (full explanation in the [How To Guide](../1%20Foundational%20Documents/1.3%20How%20To%20Guide.md)):

| Level | Artefact | Question |
| --- | --- | --- |
| Plan | [Capacity Planner](PDP%20Capacity%20Planner.xlsx) | When do I expect to complete it? |
| Learning | [Progress and Evidence Log](2.4%20Progress%20and%20Evidence%20Log.md) | What have I learned and completed? |
| Platform | [Final Project Checklist](../1%20Foundational%20Documents/1.5%20Final%20Project%20Checklist.md) | What can my platform demonstrably do? |

## Workflow

| Step | Template | What you decide |
| --- | --- | --- |
| 1 | [Personal Profile](2.1%20Personal%20Profile.md) | Goals, starting point, what “done” means for you (including optional tracks such as AI) |
| 2 | [Capacity Planner](PDP%20Capacity%20Planner.xlsx) (+ [guide](2.2%20Capacity%20and%20Timeline.md)) | Hours per week → programme duration and milestones |
| 3 | Same workbook · *Module Plan* sheet (or [Module Schedule](2.3%20Module%20Schedule.md)) | Which modules, in what order, by when |
| 4 | [Progress and Evidence Log](2.4%20Progress%20and%20Evidence%20Log.md) | What you actually learned and where the proof lives |
| 5 | [Final Project Checklist](../1%20Foundational%20Documents/1.5%20Final%20Project%20Checklist.md) | Whether each in-scope acceptance criterion is met |

**Recommended path:** fill the profile briefly, then do all planning in **`PDP Capacity Planner.xlsx`** (Google Sheets / Excel / LibreOffice). Use the Markdown files if you prefer plain text, or to keep a narrative copy of the plan in git.

## Copy before you edit

Duplicate the templates into your own notes, fork or private tracker. Keep this folder as the clean original.
