# Module Schedule

Use this if you prefer Markdown over the spreadsheet. Prefer [`PDP Capacity Planner.xlsx`](PDP%20Capacity%20Planner.xlsx) when you can — it calculates dates for you.

## Planning constants

| Field | Value |
| --- | --- |
| Hours per week | _e.g. 10_ |
| Start date | _YYYY-MM-DD_ |
| Estimate band | Low / Mid / High |
| Experience adjustment | _e.g. 0%_ |
| Buffer weeks | _e.g. 4_ |

**Formula:** `study weeks (module) = planned hours ÷ hours per week`  
**Running date:** add study weeks as you go; add buffer weeks only at the end (or spread them intentionally).
