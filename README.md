# Professional Development Plan

A **64-week, hands-on development programme** to expand software engineering skills into **DevOps, Cloud, AI and Platform Engineering**.

The goal is practical competence: learn the tools, complete real engineering labs, build an internal developer platform and pursue relevant certifications.

**Timeline:** 23 November 2026 – 26 March 2028 · **Commitment:** 8–10 hours/week · **Status:** Draft for DVT review.

## Teaching plan status

The **15-week DevOps syllabus** controls DevOps instructional content, module names, weekly learning objectives, lab assignments, and weighting. The six D01–D06 files are navigational companions; other discipline files remain draft scaffolds.

The calendar includes non-instructional Week 0 planning (16–22 November 2026) and excludes scheduled December leave periods. All Weeks 1–64 contain learning or practical project work; reviews and sign-off are external. Instructional Week 1 starts 23 November 2026 and Week 64 ends 26 March 2028.

## Individual DVT PDP milestone

**Datadog Fundamentals certification** is an individual PDP objective with a deadline of **31 March 2027**. It is distinct from the general programme's certification recommendations. See the [Datadog PDP plan](Programme-Documents/03_Certifications_and_PDP.md).

## Authoritative DevOps syllabus

The [15-week DevOps Engineering syllabus](DevOps_15_Week_Syllabus.md) remains unchanged and governs D01–D06. The former 48-week plan has been superseded; its history remains available in Git.

## Repository conventions

- Personal performance assessments, manager signatures, access credentials and confidential client information should not be committed to this public repository.
